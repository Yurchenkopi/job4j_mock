# CheckDev

## Описание проекта
CheckDev - это платформа для проведения пробных собеседований.
Основная идея заключается в проверке своих знаний по интересующим темам.

Программист выбирает нужный раздел, например, Java и интересующую тему, например, "коллекции".
Далее, он создает "собеседование", которое может быть двух типов: 
+ ты задаешь вопросы;
+ ты отвечаешь на вопросы.
Другие программисты могут  откликнуться на это собеседование в роли, противоположной той, которую выбрал автор собеседования.
Далее автор собеседования выбирает одного из желающих и проводит с ним личную беседу.

После этого автор и участник оставляют друг другу отзывы о знаниях выбранной темы.
Отзыв будет двухсторонний. То есть каждый из участников собеседования может откорректировать свои знания.

## Запуск приложения через Docker-compose
+ Открыть терминал linux
+ Установить Docker и Docker-compose
+ Склонировать проект `git clone https://github.com/yurchenkopi/job4j_mock.git`
+ Перейти в директорию проекта `cd job4j_mock`
+ Запустить приложение `docker-compose up`
+ Открыть браузер и перейти по `localhost:8080`
+ Для остановки приложения выполнить команду `docker-compose down`
